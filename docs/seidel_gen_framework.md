# 成果 3 专项：树上 Seidel 谱 ⟺ 广义谱 —— 理论框架与证明计划

**日期**：2026-09-07
**状态**：框架确立，计算证据 n≤15 完成（n=16–18 服务器在跑），证明攻关中

## 1. 定理候选（最终形式）

**Theorem（候选）**. 对任意两棵树 T, T′（n ≥ 1 阶），以下三条等价：

1. **WALK**：走数序列相同，W_k(T) = W_k(T′) 对所有 k ≥ 0
   （W_k := **1**ᵀAᵏ**1**，总走数；k ≤ n−1 已足够）；
2. **SSPEC**：Seidel 谱相同（S = J − I − 2A）；
3. **GEN**：广义谱相同（A 谱与补图 Ā 谱都相同）。

**计算证据**：n = 8..15 全树逐阶验证，三种指纹诱导的**划分完全相等**
（WALK==SSPEC==GEN 均 True；WALK≠ASPEC，ASPEC 粗得多）。
n=16..18 服务器验证进行中。
（`results/walk_census_n8-12.json`, `walk_census_n13-15.json`）

## 2. 已知部件（文献）

- **GEN ⟺ ASPEC + WALK**（Cvetković 经典公式：补图特征多项式由 A 的

- **GEN ⟹ SSPEC**：Johnson–Newman——正则正交阵 Q（Q**1**=**1**）同时

## 3. 证明骨架

总路线：①⟹③ 是唯一实质缺口（①⟹② 与 ②⟹① 由 §4 矩解缠给出；
③⟹② 已知；②⟹③ = ②⟹① + ①⟹③）。

### 3.1 关键代数杠杆（树特有）

**Sachs 定理（森林）**：树的特征多项式 = 匹配多项式：
  φ(T; x) = Σ_k (−1)ᵏ m(T, k) x^{n−2k}
故 **ASPEC ⟺ 匹配数序列 {m(T, k)}**。

缺口 ①⟹ASPEC 因此等价于纯组合命题：

> **C(μ)**：走等价的树有相同的匹配数序列 m(T, k)（k = 1..⌊n/2⌋）。

### 3.2 已验证的逐级恒等式

- m(T,1) = n−1（平凡）；
- **m(T,2) = C(n−1,2) − (W₂ − W₁)/2**。
  证明：相交边对数 = Σ_v C(d_v,2) = (Σd² − Σd)/2 = (W₂ − W₁)/2，
  其中 W₂ = Σ_v d_v²（长度 2 的走 = 以每个顶点为中心的樱桃数加边数）。
- m(T,3) 的推导需要 3-星数 Σ C(d_v,3) 与 3-边路径数 P₃ 的走数表达
  ——**当前攻关点**。

### 3.4 最有前途的结构路线：预解式/路径删除重构

对任意图，走数生成函数 W(T;x) = Σ_k W_k xᵏ = **1**ᵀ(I−xA)⁻¹**1**。
对**树**有逐元公式（Christoffel–Darboux 型，利用 u−v 路径唯一）：

  [(xI−A)⁻¹]_{uv} = φ_{T−P_{uv}}(x) / φ_T(x)

其中 T−P_{uv} 为删除 u−v 唯一路径内部顶点后余下的森林。因此

  W(T;x) = Σ_{u,v} μ_{T−P_{uv}}(x) / μ_T(x)   （树上 φ=μ）

**核心缺口 C(μ) 等价于**：有理函数 Σ_{u,v} μ(T−P_{uv}) 的分子
决定 μ_T——这是**匹配多项式的路径删除重构问题**（Kelly–Ulam
重构猜想的谱多项式版本；文献中有匹配多项式重构的部分结果可对接）。
此路线把谱问题完全转化为组合重构问题，是目前最有证明相的方向。

### 3.3 统一视角（同态计数框架）

- W_k = hom(P_{k+1}, T)（路径同态数 = 走数）；
- m(T,k) 是 kK₂ 的子图嵌入数，经划分格 Möbius 反演 = 若干森林同态数
  hom(F, T) 的整系数线性组合（F 经过 ≤2k 个顶点的森林）；
- 故 C(μ) ⟸ 更强命题：**树上的路径同态计数决定所有森林同态计数**
  （目标为树时）。这为归纳证明提供了结构：第 k 级把 m(T,k) 用
  W_≤2k−1 与低阶 m 表出。

## 4. Seidel ⟺ WALK 的矩解缠

S = J − I − 2A 的矩展开（词模型）：
  m_k := tr(Sᵏ) = Σ_{词 w∈{J,−I,−2A}ᵏ} tr(w)
含 j 个 J 的词归结为走数乘积：tr(J A^{a₁} J A^{a₂}⋯) = Π W_{aᵢ}。
逐阶结构（I 的收缩给二项系数）：

  m_k = (−2)ᵏ C_k + k(−2)^{k−1} W_{k−1} + F_k(W_0..W_{k−2}, C_0..C_{k−1})

其中 C_k = tr(Aᵏ)（闭走数；树上奇阶为 0）。

### 4.1 可证引理（已严格推导）

**L1（词展开，一般图）**：m_k(S) 是 {C_j}_{j≤k} ∪ {W_j}_{j≤k−1} 的
通用整系数多项式，首项结构如上式。（词模型 + J 词收缩引理
J Aᵃ J = W_a·J，可直接成文。）

**L2（树上的梯子，已验证前两阶恒等式）**：
- C₂ = 2(n−1)，W₁ = 2(n−1)（常数）；
- m₃ = 12W₂ + const(n) ⟹ **Seidel 谱决定 W₂ = Σd²**（C₃=0 二部性）；
- C₄ = 2W₂ − 2(n−1)（树恒等式，双计数可证）；
- m₄ = 16C₄ − 32W₃ + F(W₀..W₂) ⟹ **Seidel 谱决定 W₃**。

**梯子在 t=3 断裂（负面但重要的发现）**：m(T,3) 不能表为
W₁..W₅ 的权重≤5 有理多项式（n≤14 全树精确拟合，两次失败：
7 基与 19 基，fit_m3.py）。组合根源：m(T,3) = C(n−1,3) − X(n−3)
+ P₃ + 2S₃ 中的 S₃ = Σ_v C(d_v,3) 需要 Σd³ = W₄ − 2Y，而樱桃端度
乘积和 Y 不在低阶走数张成内。**走数序列对匹配多项式的决定是
"整体"的，不存在逐级显式小恒等式** → 证明必须走结构路线
（walk matrix 算术 / 同态计数代数），不能靠初等恒等式堆砌。

### 4.2 因此论文的诚实形态

- **可归约定理（可证）**：树上三关系等价 ⟺ C(μ)"走等价⟹同谱"
  ⟺ "走数决定匹配多项式"。归约链：Cvetković（GEN=ASPEC+WALK）+
  Sachs（树：ASPEC=匹配多项式）+ L1/L2（矩解缠）。
- **主猜想（证据型）**：C(μ) 对一切树成立——n≤17 已验证
  （48,629 棵），n=18..22 验证中。
- **子猜想**：Seidel 同谱树共享度序列（463/463 类成立）；且从不
  切换等价（0/463）。
